# Document_Parser

v.0.0.1 for the Document_Praser Project. Project's goal is to create an application that takes documents as input. Parses the meta-data and text. Then converts the text to a new .txt file before feeding that file to a locally run Ollama model for summary.

## Requirements

- Python 3.12+

## Installation

Clone the repository and enter the project directory.

Create a virtual environment:

```bash
python -m venv .venv
```
